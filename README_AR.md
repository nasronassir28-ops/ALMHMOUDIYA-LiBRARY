# المكتبة المحمودية — مشروع أندرويد أولي

يتضمن المشروع واجهة عربية خضراء وحمراء، وبحثًا في Open Library وInternet Archive، وعرض النتائج، والتحقق من ملفات PDF وEPUB في Internet Archive، ورسائل بديلة عند تعذر التنزيل.

## إنشاء APK
1. افتح مجلد المشروع في Android Studio على كمبيوتر.
2. انتظر مزامنة Gradle.
3. اختر Build ثم Build APK(s).
4. يوجد ملف APK عادةً في `app/build/outputs/apk/debug/`.

## حدود النسخة الأولية
- هذا مصدر مشروع، وليس ملف APK جاهزًا.
- لم يتم بناء المشروع أو اختباره على جهاز حقيقي في هذه البيئة.
- Open Library مصدر بيانات وفهرسة وليس ضمانًا لتنزيل الملف.
- قد تخضع ملفات Internet Archive لقيود وصول، وقد يفشل التنزيل حتى إذا ظهر الملف في البيانات.
- يجب إجراء اختبارات فعلية قبل الاعتماد عليه أو نشره.

## بناء التطبيق من الهاتف فقط عبر GitHub Actions
1. أنشئ حسابًا في GitHub إن لم يكن لديك حساب.
2. من متصفح الهاتف افتح GitHub وأنشئ مستودعًا جديدًا باسم `AlMahmoudiyaLibrary`.
3. ارفع جميع ملفات هذا المشروع إلى المستودع، مع الحفاظ على المجلدات.
4. افتح تبويب Actions ثم اختر `Build APK` واضغط `Run workflow` (أو انتظر انتهاء البناء بعد رفع الملفات إلى فرع main).
5. بعد نجاح البناء، افتح تشغيل workflow ثم نزّل artifact المسمى `al-mahmoudiya-debug-apk`.
6. فك ضغط ملف artifact، ثم افتح `app-debug.apk` وثبّته بعد السماح للمتصفح/مدير الملفات بتثبيت التطبيقات من هذا المصدر.

هذه الطريقة تبني APK في خوادم GitHub، فلا تحتاج إلى حاسوب، لكن تحتاج اتصال إنترنت وحساب GitHub. لم يتم اختبار workflow فعليًا حتى الآن.
